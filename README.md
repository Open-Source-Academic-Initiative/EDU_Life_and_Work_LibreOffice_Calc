# EDU: Life and Work - LibreOffice Calc for SMEs

## 📌 Context & Motivation

In Colombia and across Latin America (LATAM), millions of micro and small enterprises (SMEs) still rely on paper notebooks to manage their daily operations, inventory, and finances. Transitioning to digital tools is often hindered by the digital divide and the fact that traditional software courses are overly academic, abstract, or targeted at corporate environments.

This repository hosts an open-source, SCORM-compliant micro-course designed specifically for **non-technical human talent** (shopkeepers, hardware store clerks, warehouse assistants, and small business owners).

**The Pedagogical Approach:**
Instead of teaching "Database Normalization" or abstract formulas, this course uses a highly practical, scenario-based narrative. The learner is tasked with helping "Don Manolo," the owner of a fictional local hardware store (*Ferretería La Universal*), to migrate his messy paper notebook into **LibreOffice Calc** (a free, open-source spreadsheet tool).

*Note: While this documentation is in English for international cooperation and development purposes, the actual course content and UI are entirely in **Spanish**, tailored to the LATAM context.*

## 🏗️ Technical Architecture

This project is built with a focus on simplicity, portability, and automation. It does not require a complex Node.js/NPM environment.

The core of the project is managed by a Python orchestrator (`setup_project.py`) that generates a self-contained, responsive HTML5 Single Page Application (SPA) styled with Tailwind CSS, ready to be packaged for any LMS (like Moodle).

### Project Structure

The repository relies on an infrastructure-as-code approach. The primary workspace is the `curso_calc_universal` directory, which is autogenerated and maintained by our utility scripts.

    EDU_Life_and_Work_LibreOffice_Calc/
    ├── README.md                      # This file
    └── curso_calc_universal/          # ⚠️ Auto-generated project workspace
        ├── curso_la_universal.html    # Main SPA course file
        ├── imsmanifest.xml            # SCORM configuration
        ├── multimedia/
        │   └── img/                   # Course assets and images
        └── scripts/
            ├── setup_project.py       # Master orchestrator script
            ├── empaquetar_scorm.py    # SCORM .zip packager
            └── optimize_images.py     # Image compression utility (Pillow)

## 🚀 Quick Start & Development

To work on this project locally, you only need Python installed on your machine.

### 1. Initialize the Project Workspace

If you are cloning this repository for the first time, you must run the master orchestrator to generate the workspace and the HTML files.

    # Navigate to the scripts folder (or wherever setup_project.py is located)
    python scripts/setup_project.py

*This will create/update the `curso_calc_universal` directory, build the HTML course, and place the utility scripts inside `curso_calc_universal/scripts/`.*

### 2. Local Testing

Since the course is a self-contained HTML file without external JS frameworks, you can simply open it in your browser:

    # Open the file directly in your preferred browser
    open curso_calc_universal/curso_la_universal.html

### 3. Image Optimization

The course relies on high-quality images that need to be compressed for web/LMS delivery to save bandwidth for users on mobile networks. Place your high-resolution images in `curso_calc_universal/multimedia/img/` and run:

    cd curso_calc_universal
    python scripts/optimize_images.py

*This script will backup your raw images into an `originales/` folder and compress the active files to a web-friendly size.*

### 4. Build the SCORM Package

Once the HTML is tested and images are optimized, you can build the SCORM `.zip` package for Moodle integration:

    cd curso_calc_universal
    python scripts/empaquetar_scorm.py

*This will output `Curso_Calc_LaUniversal_SCORM.zip` in the root of your workspace, ready to be uploaded to your LMS.*
